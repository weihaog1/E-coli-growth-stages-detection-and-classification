**Project Title: Detecting and classifying *E. coli* growth stages with convolutional neural networks**


**1\. Project Summary**

This project aims to automate the detection and classification of *E. coli* bacteria into three distinct growth stages (rod-shaped, dividing, and microcolony) using bright-field microscopy images. We will implement and compare a classical Convolutional Neural Network (CNN) trained from scratch against the state-of-the-art YOLOv8 object detection model, using an *E. coli* growth stage object detection dataset (\~160 images). The images will be additionally augmented to balance classes and fully utilize dataset information for training/testing. Model evaluation will be based on mean average precision (mAP), F1-score, and confusion matrices. 

**2\. Problem Definition**  
Many microbiology labs could greatly reduce their manual workload by using object detection networks to automatically identify and classify bacteria in microscopy images. The problem we are addressing is the automation of this analysis to increase throughput, consistency, and accuracy. In this project, inputs for our models will be microscopy images of *E.* *coli* growth stages generated by a single lab. The models will output bounding boxes localizing individual cells and class labels indicating their specific growth stages (rod, dividing, microcolonies). 

Previous approaches have utilized object detection models like YOLOv4, EfficientDet, and SSD-MobileNetV2 to address similar tasks (Chin et al., 2024), with reliance on heavy augmentation to overcome small dataset sizes. While these models have shown promise, newer architectures like YOLOv8 offer potential improvement in inference speed and detection accuracy. We aim to implement and benchmark SOTA approaches against a classical baseline (custom CNN trained from scratch) to examine the benefits and drawbacks of complex architectures in biological domains.

**3\. Proposed Technical Approach**

The pipeline:

1. Preprocessing: Raw images (256x256, grayscale), will be converted and resized to standard input dimensions  
2. Data Augmentation: To address the small dataset size (\~160 images) and significant class imbalances  
   1. Geometric: Random rotations, horizontal/vertical flips  
   2. Pixel-level: Denoise, brightness/contrast adjustments, and blurring.  
3. Model implementation  
   1. Classical model(baseline): We will train a CNN classifier from scratch on fixed-size patches cropped from the training data (labeled as one of the three growth stages or background). For inference, we will slide a window across the full test images to identify candidate regions and use Non-Maximum Suppression (NMS) to merge overlapping detections into final bounding boxes.  
   2. Modern Model(YOLOv8): We will implement YOLOv8, utilizing transfer learning from weights pre-trained on the COCO dataset. We will fine-tune the prediction head for our specific 3-class biological problem,  
4. Loss Functions:  
   1. For custom CNN: We will use Cross-Entropy Loss, The sliding window CNN will act as a multi-class classifier with 4 classes (the 3 cell stages \+ background).   
   2. For YOLOv8: YOLOv8 uses a composite loss function. Which includes Complete Intersection over Union (CIoU) Loss for accurate bounding box regression, Distribution Focal Loss (DFL) for refining box boundaries, and Binary Cross-Entropy for class probability.

**4\. Data Sets**

We will use the DeepBacs E. coli growth stage object detection dataset, available via Zenodo.

* **Source:** Spahn et al. (2021) / Zenodo. [https://zenodo.org/records/5551016](https://zenodo.org/records/5551016)  
* **Content:** \~160 paired bright-field microscopy images with manual annotations.  
* **Classes:**  
  1. **Rod-shaped cells:** (Majority class, single cells)  
  2. **Dividing cells:** (Intermediate class, cells undergoing fission)  
  3. **Microcolonies:** (Minority class, defined as 4+ cells in close contact)  
* **Format:** Images are 256x256, grayscale, 8-bit PNGs. Annotations are provided in xml format (we will convert it to YOLO txt format).  
* **Strategy:** We plan to analyze the class distribution to identify imbalance ratios. Due to the small sample size, we will generate a synthetic "Augmented Training Set" containing approximately 1,000+ images to prevent overfitting and improve  After augmentation, the data will be split into **70% training, 20% validation, and 10% testing**.

**5\. Experiments and Evaluation**

We will evaluate our models using standard object detection metrics to ensure comparability 

Metrics:

- Mean Average Precision  
- Precision and Recall  
- F1-Score  
- Confusion Matrix

Experimental plan

- Baseline Experiment: Train custom classical models and pre-trained models (YOLOv8) on the original, unaugmented dataset.  
- Augmentation Experiment: After identifying class imbalances, geometric and pixel-level augmentations of the original images and corresponding annotations will expand the dataset and prevent model overfitting  
- Comparison: We will use standard metrics such as confusion matrices to evaluate individual model performances and compare pre-trained and custom models. We will also compare their performance before and after data augmentation.
